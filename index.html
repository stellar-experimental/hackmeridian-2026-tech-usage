How these were counted

Intent
The project's submission form or a README names the tool. It may be a plan or just a reference, so it does not prove the project used it.
Code
The project's repo installs the tool, imports its SDK, calls its API or sets it up in config. A name in a comment or a UI list does not count. Some API-only uses are missed.
Guava recap
Guava's post-event report counts differently, so its number appears only when you hover a row.
How far to trust it
Code counts: about 80% confident. Intent counts: about 65% confident. 18 of 164 repos could not be read and are not counted.
Safe to say
Which tools are used more than others, and rough shares like "about 4 in 10 projects used an ecosystem tool in code". Treat exact counts as approximate.
Rows overlap
One project can appear in several rows, so the rows do not add up to 146.
