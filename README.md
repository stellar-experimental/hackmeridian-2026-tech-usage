# What HackMeridian 2026 projects built on

A chart of which Stellar tools, privacy contracts, agentic tools and ecosystem tools HackMeridian 2026 projects used.

- `index.html` is the chart (served with GitHub Pages).
- `data-points-corrected.csv` lists the data points for the recap video, with intent and code counts.

## How it was counted

Both measures cover the 146 of 164 submissions whose repos could be read.

- **Intent:** the submission form or a README names the tool. It may be a plan, so it does not prove use.
- **Code:** the repo installs the tool, imports its SDK, calls its API or sets it up in config. A name in a comment or a UI list does not count.

Code counts are about 80% confident and intent counts about 65%. Treat exact counts as approximate.
